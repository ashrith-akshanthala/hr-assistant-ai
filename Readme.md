# HR Assistant AI
An AI-powered chatbot for employees to manage leaves and query company policies.

## Features
- Leave application and balance enquiry via natural language
- FAQ on company and leave policies using RAG
- Semantic search using SentenceTransformers (all-MiniLM-L6-v2)
- LangChain Agent with custom tools

## Tech Stack
- Python, LangChain, Ollama (local LLM)
- RAG pipeline with SentenceTransformers
- Tools: get_employee_data, apply_leave, check_leave_balance
